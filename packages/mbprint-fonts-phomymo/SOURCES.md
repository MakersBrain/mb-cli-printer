# Font sources

The font files and per-family `OFL.txt` files were copied from the
[Google Fonts repository](https://github.com/google/fonts) at commit
`ec626514f79f831f1ab848a82114a0ce7e2d6372`.

All ten families are licensed under the SIL Open Font License 1.1. Variable
fonts are retained where supplied upstream; Lato uses the four static faces
needed by mbprint.
